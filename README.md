User Manual: Local EdTech platform (with cross-platform hosting).

📌 What you need to work
Before starting, make sure the following are installed on your computer:
Node.js (for the Vite server) - https://nodejs.org/en/download
Python (for the course indexing script) - https://www.python.org/downloads/

LAUNCH

1 To launch, you need to download the latest archive from releases - [https://github.com/Dmitry-II/EdTech/releases/tag/v2.1]
2 After downloading, unpack it in a convenient location
3 Run EdTechLauncher.exe
4 Enter your domain (ANY NAME IN LATIN CHARACTERS WITHOUT SPECIAL CHARACTERS, !!!!!!!! ! ! USUALLY SERVEO PROVIDES ONLY 1 POSSIBLE DOMAIN FOR 1 IP ! ! ! !!!!!!!)
5 Click the start button and click the "Open site in browser" button

ADDING YOUR COURSES

1 To add your modules, create the path public -> courses -> course folder (with your course name) -> your course modules folder -> videos in any formats (other data types are ignored)
3 Stop site hosting with the Stop button
2 Restart EdTechLauncher.exe

TROUBLESHOOTING

Most errors occur because some elements failed to load; you need to read the log in the lower-left corner of the application and download the necessary element
